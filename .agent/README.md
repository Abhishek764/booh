# Agent Collaboration Records

Each agent-owned task has a result file under its assigned directory. The
required file is `RESULT.md`, using the fields in the existing templates. Fill
every field, using `N/A` where a category does not apply. Do not place secrets,
tokens, credentials, prompts containing private data, or real baby data in an
agent result.

Before working, agents must read `CONTEXT.md`, `AGENTS.md`, `SECURITY.md`, and
the assigned task in `TASKS.md`. After working, update the result file and
report tests, security review, commit, known issues, and the next dependency.
